Come sit in the room.

#thealpha is an open channel for anyone curious about the work — questions, corrections and long conversations all welcome. Pick your device, install one app, and you are in.

📱

Revolution IRC Free · open source

The best Android IRC client — solid TLS support, IRCv3, several servers in one app, and no ads. It is no longer on Google Play, so install it from F-Droid.

Get it on F-Droid ↗ Source code ↗
  1. Open the app and tap Servers → + to add a server.
  2. Address irc.thealpha-secret.xyz, port 6697, and switch TLS/SSL on.
  3. Pick any nickname, then tap Connect.
  4. Type /join #thealpha and say hello.
🍎

Igloo Free

A modern iPhone and iPad IRC client with TLS, push notifications and a clean interface — the smoothest way onto #thealpha from iOS.

Get it on the App Store ↗
  1. Open Igloo and tap + to add a network, then choose Add manually.
  2. Host irc.thealpha-secret.xyz and port 6697, with SSL/TLS enabled.
  3. Add channel #thealpha before connecting, or join it afterwards.
  4. Pick any nickname and connect.
💻

Halloy Free · open source

A fast, modern IRC client for macOS, Windows and Linux — the recommended pick for a desktop window. Prefer a terminal? WeeChat runs anywhere and does everything.

Download Halloy ↗ Get WeeChat ↗
  1. In Halloy, add a server — host irc.thealpha-secret.xyz, port 6697, TLS on.
  2. Nickname: anything you like. Channel: #thealpha.
  3. WeeChat users, two commands: /server add alpha irc.thealpha-secret.xyz/6697 -ssl then /connect alpha.
🌐

KiwiIRC Nothing to install

No app and no account — a complete IRC client in a browser tab. The link below is already filled in with this network's address, port and channel; choose a nickname and press Start.

Open the web client ↗
  1. Click the button above and enter any nickname.
  2. Channel #thealpha is preset — press Start.
  3. The best option on a phone whose carrier blocks port 6697 (see the note).
